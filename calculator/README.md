# Калькулятор

Упрощённая модель для сравнения вариантов вложения: обычный брокерский счёт и ИИС-3.

**Что считает:**
- рост капитала при ежемесячной капитализации;
- регулярные ежемесячные взносы;
- налог 13% с дохода на брокерском счёте (без учёта льготы долгосрочного владения);
- ИИС-3: вычет 13% со взносов (база до 400 000 ₽ в год) довносится на счёт ежегодно, доход не облагается.

**Запуск** (Python 3, без дополнительных библиотек):
```bash
python3 kalkulyator.py
python3 kalkulyator.py --start 100000 --monthly 10000 --rate 14 --years 10
```

**Параметры:**
- `--start` — начальная сумма, ₽ (по умолчанию 100 000)
- `--monthly` — ежемесячный взнос, ₽ (по умолчанию 0)
- `--rate` — доходность, % годовых (по умолчанию 14)
- `--years` — срок, лет (по умолчанию 5)

**Пример вывода:**
```
Старт 100 000 ₽, взнос 0 ₽/мес, 14% годовых, 5 лет
  Без налога:          200 561 ₽
  Брокерский счёт:     187 488 ₽
  ИИС-3 (+вычеты):     226 139 ₽
```
